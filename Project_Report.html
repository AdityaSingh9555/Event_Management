🚀 Project Overview

EventHub is a premium ticketing platform designed to bridge the gap between event organizers and attendees in India. It focuses on localization, high-end aesthetics, and a friction-less user experience.

The Problem

Cluttered interfaces and lack of local context in existing platforms.

The Solution

A "Premium-First" design with INR support and interactive venue maps.

✨ Core Features

For Attendees

  • Category-based discovery
  • Smart Cart with Promo Codes
  • Secure E-Tickets with QR Codes
  • Google Maps Integration

For Organizers

  • Real-time Sales Analytics
  • Event Management Dashboard
  • Secure Check-in Scanner
  • Data Export & Reporting
